Part C crash course

In Part C you look at an ore sample and say what type of deposit it comes from. This page teaches only that. You need about 12 deposit types, and for each one you need one or two strong clues. Read the cards, try the sorting tool, then do the quiz.

How to answer

Ian explained the format in the lab revision class (10 Nov). You write bullet points. The deposit type comes first, because it is the main answer. Then you give the evidence. You don’t need the name of the mine or deposit.

Memorise
  1. Deposit type (VMS, SEDEX, porphyry Cu, and so on)
  2. Ore and gangue minerals you can see
  3. Texture: banded, massive, vein, stockwork, breccia, disseminated
  4. Host rock and alteration
  5. Syngenetic or epigenetic: formed at the same time as the host rock, or later
  6. Temperature and depth
  7. Setting: where and how it formed
At the lab test
  • If the specimen is only host rock or gossan, say so. Then name the deposit type it belongs to.
  • Your printed cheat sheet has all of this on pages 1 to 3, plus the simulation samples A to I.

Find the type in a few questions

Answer each question about the specimen in front of you. The tool takes you to the right card below. Try it with a photo from the quiz, or with your simulation samples.
